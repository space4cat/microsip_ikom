# MicroSIP (ikom) — кастомная портабельная сборка

Портабельная (portable) сборка MicroSIP 3.22.3 с кастомной функцией
**красного предупреждения «ВНИМАНИЕ! Контрольный звонок!»** для выбранных
номеров при входящих звонках.

## Состав

| Файл | Назначение |
|---|---|
| `microsip.exe` | Портабельный MicroSIP 3.22.3 (x86), без видео |
| `microsip.ini` | Конфигурация с предустановленным URL контрольного списка номеров |
| `unblock.bat` | Снимает блокировку SmartScreen с `microsip.exe` (запустите один раз) |
| `langpack_russian.txt` | Русская локализация (удалите файл для англ. интерфейса) |

Файл `microsip.ini` уже содержит предустановленный URL контрольного списка,
обновление каждые 60 минут:

```ini
[Settings]
attentionNumbersUrl=http://10.100.0.6/microsip_webmn/list.php?token=...
attentionNumbersRefresh=60
```

Остальные настройки и контакты создаются автоматически рядом с exe при первом
запуске: `microsip.ini`, `Contacts.xml`. Если `microsip.ini` уже был создан
(вы запускали exe раньше), добавьте две строки выше вручную в секцию `[Settings]`.

## Установка

1. Скачайте файлы в любую папку (например `C:\MicroSIP`).
2. Если Windows показывает предупреждение SmartScreen — запустите `unblock.bat`
   (один раз), либо нажмите «Подробнее» → «Выполнить в любом случае».
3. Запустите `microsip.exe`. Ничего устанавливать не нужно.
4. Для переноса на другой компьютер — просто скопируйте папку целиком.

## Настройка учётной записи

В главном окне: меню **File → Settings → Accounts** (или иконка аккаунта),
добавьте SIP-аккаунт (сервер, номер, логин/пароль, как у вашего провайдера).

## Красное предупреждение при входящем звонке

Когда входящий звонок поступает с номера из списка, в окне входящего звонка
появляется красная надпись **«ВНИМАНИЕ! Контрольный звонок!»**.

### Настройка списка номеров

Откройте `microsip.ini` (создаётся после первого запуска) и в секции `[Settings]`
укажите номера:

```ini
[Settings]
attentionNumbers=4951234567;+74951234567;800*
attentionNumbersUrl=
attentionNumbersRefresh=60
```

- **`attentionNumbers`** — список номеров/масок. Разделители: `;` `,` `|` или
  перевод строки.
- Маски: `*` — любое количество символов, `?` — один символ.
  Примеры: `495*` (все номера, начинающиеся с 495), `*123?` (оканчивающиеся
  на «123X»), `84951234567` (точный номер).
- Строки из списка, начинающиеся с `#` или `;` — игнорируются (комментарий).

### Обновление списка с URL по расписанию

Список можно хранить на сервере и обновлять автоматически:

```ini
attentionNumbersUrl=https://example.com/microsip-numbers.txt
attentionNumbersRefresh=60
```

- **`attentionNumbersUrl`** — адрес текстового файла (UTF-8) со списком номеров
  (тот же формат: разделители `;` `,` `|` или строки).
- **`attentionNumbersRefresh`** — интервал обновления в минутах (минимум 15).
- При каждом успешном обновлении список полностью заменяется содержимым URL.
- При недоступности URL или коде ответа != 200 список сохраняется прежним.

В комплектном `microsip.ini` URL уже указан и ничего настраивать не нужно.
Чтобы отключить обновление с URL, поставьте пустое значение:
`attentionNumbersUrl=`.

### Проверка работы

1. Настройте список (например `attentionNumbers=77777777777`).
2. Позвоните с номера 77777777777 на свой аккаунт.
3. В окне входящего звонка появится красная надпись «ВНИМАНИЕ! Контрольный звонок!».

## Дополнительно

- **Перезапуск после правок ini** — изменения `microsip.ini` вступают в силу
  после перезапуска MicroSIP (либо сохраняются через меню настроек).
- **Локализация** — для английского интерфейса удалите `langpack_russian.txt`.
- **Логирование** — файл `microsip_log.txt` рядом с exe появляется при включённом
  логе в настройках.
